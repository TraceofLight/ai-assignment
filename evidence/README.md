# 공개 증빙 표기 기준

실제 실행 결과에서 과제 관련 부분만 발췌했다. `<PUBLIC_IP>`, `<ADMIN_IP>`, `<REGION>`, `<..._OCID>`는 실제 값의 비식별 표기이며 재현 명령에서는 자신의 값으로 채운다. 성공·실패 결과는 변경하지 않았다. 기존 서비스와 서버 전체 상태 기록은 포함하지 않는다. 스크린샷은 실습 서비스 화면 및 발췌 로그의 브라우저 열람 화면이다.

[SSH 실행 로그](ssh-session.txt)는 관리자 PC에서 수집한 실제 `ssh -v` 출력의 관련 행과 원격 stdout이다. `<MANAGEMENT_IP>`, `<KNOWN_HOST_ALIAS>`, `<SSH_USER>`, `<SSH_KEY_FILE>`, `<KEY_FINGERPRINT>`는 비식별 값이다. 기존 사설 관리망을 통한 접속이며 공인 주소 접속 성공으로 해석하지 않는다.
