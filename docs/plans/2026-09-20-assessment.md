# SQL 사전평가 보완 계획

목표: 기존 SQL 동작을 유지하면서 평가 15개 항목의 설명과 실행 증빙을 연결하고 현재 b5-1 브랜치에 push한다.

설계: README 전체 재작성, 별도 해설서 추가, 기존 설명의 빈틈 보완을 비교했다. 중복을 줄이는 세 번째 방식을 선택한다. 소크라테스 문답 기록과 평가 근거 색인을 별도로 제공한다. 캡처는 Python sqlite3 실행 클라이언트에서 새 메모리 DB에 Q01~Q15를 순서대로 실행한 실제 결과를 사용한다.

1. README의 정규화·PK/FK·샘플 근거를 확장하고 Q10/Q12의 포함 범위 및 SQLite 타입 설명을 교정한다. 검증: 원본 SQL 및 실제 계산 결과 대조.
2. SQL의 의도·관계·인덱스 주석을 보강한다. 검증: 기존 파이프라인 통과 및 쿼리 15개 유지.
3. 실행 화면과 Q15 이후 JOIN 비교를 추가한다. 검증: SQL·결과가 함께 보이는 JPEG 16개와 텍스트 일치 확인.
4. 서브에이전트 검토 후 명시적 파일만 커밋하고 origin/b5-1에 push한다. 검증: 원격 브랜치와 로컬 커밋 일치.

기존 미추적 개발 파일은 작업 대상에서 제외한다. 검증은 로컬 Python으로 수행하며 Docker 실행 여부는 별도로 보고한다.
