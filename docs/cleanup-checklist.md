# 실습 구성 정리 체크리스트

기존 인스턴스 운영 규약에 따라 공유 인스턴스·볼륨·네트워크는 유지한다. 현재 서비스도 유지 중이며 **아래 실환경 원복은 실행하지 않았다**. 정리 범위는 실습에서 추가한 구성뿐이다.

| 대상 | 정리 범위 |
|---|---|
| 실습 컨테이너 | 이름과 `assignment=b6-1` 라벨이 일치하는 컨테이너만 제거 |
| UFW | 실습에서 추가한 HTTP/HTTPS 규칙만 제거 |
| OCI NSG | 현재 연결 목록에서 실습 NSG만 분리하고 다른 참조가 없으면 제거 |
| IAM | 실습 정책 제거 후 다른 참조가 없는 실습 Dynamic Group 제거 |
| DNS | 실습용으로 추가한 레코드만 제거 |
| 파일·이미지 | 필요한 증빙 보관 후 실습 경로와 재사용되지 않는 이미지 정리 |
| 공유 Compute·볼륨·공인 IP·VCN·Subnet·IGW | 보존 |

## 실행 순서

- [ ] 현 운영 규약과 정리 대상, 후속 변경 여부 확인.
- [ ] 현재 컨테이너 이름·라벨과 UFW 규칙의 고유 comment 확인.
- [ ] `sudo bash /opt/b6-1-cloud-lab/rollback.sh` 실행. 스크립트는 대상 불일치 시 중단하며 OCI/DNS는 별도로 정리.
- [ ] OCI VNIC의 최신 NSG 목록에서 실습 NSG만 제외. 최신 `etag`와 `--if-match`로 다른 변경 덮어쓰기 방지.
- [ ] 다른 연결·참조가 없는 실습 NSG, IAM 정책·Dynamic Group 제거.
- [ ] SSH 접근 제한은 운영 규약을 유지. 과거 전체 공개 설정으로 자동 복구하지 않음.
- [ ] 실습 DNS 레코드, 재사용되지 않는 이미지 및 전용 파일 정리.
- [ ] 공유 자원과 기존 서비스에 영향이 없는지 운영 규약에 따라 확인.
- [ ] 수행 시각·제거 대상·결과 기록. 실행하지 않은 항목을 완료로 표시하지 않음.

`docker system prune`, 전체 방화벽 복원, 공유 자원 종료·삭제는 수행하지 않는다. 인증 자료의 관리는 별도 운영 규약을 따른다.

## 모의 검증

[격리된 모의 실행 결과](../evidence/rollback-safety.txt): 규칙 변경·라벨 불일치 시 중단, 정상 정리, 이미 없는 상태의 네 경우를 검증했다. 실제 서버 삭제 실행 증빙이 아니다.
